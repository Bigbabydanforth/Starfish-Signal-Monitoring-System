# Starfish Signal Dashboard

A modern React & Express web application for managing and pushing B2B intent signals to HubSpot for Starfish Co.

---

## Overview

The **Starfish Signal Dashboard** provides a single-pane-of-glass view for the team (David, Zack, Andrew, Cole) to review incoming intent signals generated by the Starfish Signal Monitoring System. 

### Key Features
- **Supabase Authentication**: Secure login for authorized team members.
- **Signals Table & Filtering**: Client-side filtering by Signal Type and Priority, with status chips and real-time status management.
- **Signal Detail View**: Two-column layout with signal trigger context, AI-generated brief & contact approach, raw contact metadata, and BSI broadcast schedule.
- **1-Click HubSpot CRM Integration**: Pushes verified contact and company data directly to HubSpot CRM via Express backend API (`server/routes/hubspot.js`) and auto-triggers sequence routing.

---

## Tech Stack

- **Frontend**: React 18, Vite, TailwindCSS, Axios, React Router v6
- **Backend API**: Express.js (`server/server.js`)
- **Authentication**: Supabase Auth
- **CRM**: HubSpot REST API v3
